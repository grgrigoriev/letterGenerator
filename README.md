# 📝 Letter Generator

Автоматический генератор сопроводительных писем на основе PDF-вакансий с глубокой аналитикой соответствия.

Инструмент анализирует вакансию, сравнивает её с твоим профилем, выдаёт структурированный отчёт о соответствии (включая процент совпадения и таблицу навыков) и генерирует креативное, нешаблонное сопроводительное письмо — всё это **локально**, без отправки персональных данных в облако.

## ✨ Возможности

- 📄 **Парсинг PDF-вакансий** — автоматическое извлечение текста из PDF-файлов (hh.ru, getmatch, LinkedIn и др.)
- 🧠 **Двухэтапная генерация с помощью локальной LLM**:
  - **Аналитический блок**: процент соответствия, таблица пересечения навыков, сильные стороны, зоны роста, рекомендации по ключевым словам
  - **Креативное письмо**: живой, нешаблонный текст без канцелярита, с акцентом на результаты и цифры
- 🔒 **Полная приватность** — все данные (профиль, вакансии, письма) обрабатываются локально через LM Studio
- 💾 **Автосохранение** — каждое письмо и аналитика сохраняются в папку `output/` с временной меткой
- 🎯 **Адаптивность** — один профиль, любое количество вакансий; акценты подстраиваются под конкретное предложение

## 🚀 Быстрый старт

### Требования

- **Node.js** 22+ ([скачать](https://nodejs.org/))
- **LM Studio** ([скачать](https://lmstudio.ai/)) с загруженной моделью Qwen (рекомендуется `qwen/qwen3.8-27b` или аналог)
- **macOS** / **Linux** / **Windows** (терминал с поддержкой bash/zsh)

### Установка

Клонируйте репозиторий
git clone https://github.com/grgrigoriev/letterGenerator.git
cd letterGenerator
Установите зависимости
npm install


### Настройка

1. **Запустите LM Studio** и загрузите модель Qwen (например, `qwen/qwen3.8-27b`).
2. Включите **Local Server** (вкладка `<->` слева) и убедитесь, что сервер запущен на порту `1234`.
3. Отредактируйте файл `profile.txt` — впишите туда свой актуальный профиль (опыт, навыки, достижения). Чем подробнее он будет, тем точнее модель подберёт акценты.

### Использование

```bash
# Генерация письма для PDF-вакансии
node generateLetter.js "/путь/к/вакансии.pdf"

Пример:
node generateLetter.js "./vacancies/rtlabs_qa_engineer.pdf"

После запуска в консоли появится:
📊 Аналитика соответствия — процент, таблица навыков, рекомендации
✉️ Сопроводительное письмо — готовый текст для отклика
Оба файла автоматически сохранятся в папку output/:
cover_letter_YYYY-MM-DDTHH-MM-SS.txt — полный отчёт (аналитика + письмо)
analysis_YYYY-MM-DDTHH-MM-SS.txt — только аналитика
